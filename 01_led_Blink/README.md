# STM32 LED Blink

## Objective
Blink an LED using STM32 to understand GPIO configuration and basic HAL functions.

## Board
Nucleo-G070RB

## Tools Used
- STM32CubeIDE

## Description
This project demonstrates basic GPIO output control on STM32.
The LED is toggled using HAL_Delay inside the main loop.
